# Weakness mitigations (Co-Agent v0.2)

Each known weakness has a **hard rule** in identity, scenario, or scaffold.

| Weakness | Mitigation in v0.2 |
|----------|-------------------|
| **Paste load** | N default 1; N=4 rare; **one active LETTER thread**; prefer PIPELINE for heavy phases; carrier templates |
| **Header discipline** | Body-only = **no relay**; templates include headers |
| **Same-provider panes** | Roster records provider; playbooks **prefer cross-provider** challenger; code names mandatory for same host |
| **Sycophancy / correct→incorrect** | Blind isolate; concede only on evidence; **STRUCTURED_DISAGREEMENT** legal; stop on no new evidence; anti-sycophancy lines in Fold 5 |
| **Role soup** | Scenario: **one primary job per seat**; hierarchy LEAD > … explicit |
| **Delegation creep** | Only Commander/LEAD mission-delegate; A-seats peer-check only if allowed |
| **Hivemind sovereignty creep** | Skill card: process hive only; LEAD + Commander seal non-negotiable |
| **Install timing** | Archive pack only; no claim of live canon |
| **No dual-API** | Carrier templates; silent paste is the supported runtime |
| **Overhead vs gain** | Default Co-Agent **no**; minimal scenario path; council = light path |
