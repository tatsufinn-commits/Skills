# Professor / instructor public footprint by course code

## Procedure

1. Inputs: course code (required), instructor name (optional).  
2. Official: directory, course page, syllabus if public.  
3. Web: `{CODE} Mapua {name} professor|instructor`.  
4. Secondary: Reddit/forums — teaching-style anecdotes only as secondary.  
5. No private groups; no non-public contact harvest.  
6. Output: MAPUA_PACK with clear separation official role vs anecdote.

## Failure

If only gossip: FOUND_SECONDARY_ONLY or NOT_FOUND_PUBLIC — never a confident “personality dossier” as fact.
