### VERDICT

**CONDITIONAL — not green-light-ready as shipped, and close.** The package does what it
claims at the *documentation* level with unusual epistemic honesty ([N]/[I]/[O] labels,
decay dates, self-declared authored-not-run exemplars, two explicit requests for a
second operator). The three mandated eval commands reproduce exactly. But the
*programmatic gate* — the thing that makes "the disciplined path the default path"
machine-checkable — has a hole that lets through exactly the configuration this skill
exists to prevent (F1), plus bypasses in every law-adjacent regex. As a v0.1
design-of-record: strong. As an automated gate standing between a worksheet and a green
light: not yet.

### FINDINGS (evidence-cited; all probes reproducible with `reimagine_v0.1/evals/grader.py` + the mutated exemplars)

1. **[HIGH] F1 — Gate 0 hole: photo present with no rights source passes 6/6.**
   `evals/grader.py` C3 accepts `PHOTO_SOURCE ∈ {own, licensed, cleared, none}`
   unconditionally. With `PHOTO: yes` + `PHOTO_SOURCE: none` the package passes all six
   checks (probe H1). Gate 0 (PROC_REIMAGINE Stage 1; INTAKE_FORM Field 1) says
   rights-unclear → STOP. A worksheet that admits "no source" for the photo it ships is
   the canonical G1 violation, and the grader waves it through. Fix: when `PHOTO=yes`,
   eligible set = {own, licensed, cleared} only; `none` only with `PHOTO=no`.

2. **[MED] F2 — placeholder scan misses every section except paste text + key values.**
   `PLACEHOLDER_RE` is applied to `scanned = paste + keys` only (grader.py C1).
   `⟨TODO: count the bays⟩` in the preserve list and `⟨material TBD⟩` in the alter list
   → 6/6 PASS (probe H2), contradicting `scaffolding/CONFIG_WORKSHEET.md`: "Replace
   every ⟨…⟩ before emitting — no placeholders survive to a PASS."

3. **[MED] F3 — C2/C6 print detail lines that contradict the FAIL verdict.**
   `"; ".join(problems) or "..." if photo == "yes" else "..."` parses as
   `(A or B) if C else D`, so with `PHOTO: maybe` the output is
   `FAIL C2 | text-only brief correctly drops fidelity claims` (real problem discarded);
   `SCHOOL: maybe` → `FAIL C6 | no school context — disclosure N/A` (probes H3a/H3b).
   A Desk reading logs sees a FAIL wearing a PASS explanation. Parenthesize the ternaries.

4. **[MED] F4 — reject-drift "rule" = two word occurrences; QA parser has a swallow trap.**
   Replacing the rule with "policy note: we never reject outputs; drift is acceptable"
   → 6/6 PASS (probe H5b), because C4 only asks that "reject" and "drift" co-occur in
   the section. Worse, while probing I found `parse()` matches `^([A-Z][A-Z_]*):` on ANY
   line, so an in-section line like `NOTE: bay count waiver approved by studio` is
   silently absorbed as a key and removed from the section text (probe H5d) — relevant
   to any attempt to anchor the rule check on an in-section line. Require the affirmative
   form (e.g. line starting `REJECT-DRIFT RULE:` containing "reject" AND
   "redo"/"authoritative"), and either stop parse() swallowing section lines or document it.

5. **[MED-LOW] F5 — C5 "traceability" is format-only.** `CARD: T99` (exists in no atlas;
   the 34 real IDs are enumerable in `references/atlas-router.md`) +
   `RATIONALE: aaaaaaaaaaaaaaa` (15 chars, the floor) → 6/6 PASS (probe H6). VECTORS.md
   advertises "valid card ID … substantive rationale." Embed the 34-ID set; raise the
   rationale floor (~40+ chars).

6. **[MED-LOW] F6 — CMI regex is one phrase wide.** FORBIDDEN_RE only matches
   `(remove|erase|strip|clean) (the)? (watermark|credit)`. "watermark removal … delete
   the watermark" in the paste text → 6/6 PASS (probe H7); `test_grader.py` only tests
   "remove the watermark". Either widen (removal/deleted/scrub/… plurals) or state in
   VECTORS.md that C3 is a lexical tripwire, not enforcement.

7. **[LOW] F7 — named-style check is one phrasing wide.** `style of\s+[A-Z]` misses
   `STYLE_AUTHORITY: in the manner of Zaha Hadid` → 6/6 PASS (probe H8), though the card
   FORBIDDEN bans named living-architect imitation outright (legal-postures "Style
   authority" rung).

8. **[LOW] F8 — no word boundaries on todo/tbd.** `PLACEHOLDER_RE` flags legitimate text:
   TASK "todos: re-imagine…" → C1 FAIL `['todo']` (probe H4).

9. **[LOW] F9 — path errors are indistinguishable from failed worksheets.**
   `python3 evals/grader.py /nonexistent/file.md` → raw FileNotFoundError traceback,
   exit 1 — the same exit code as a genuine FAIL (usage errors correctly use exit 2).
   In CI, a typo silently reads as "worksheet failed" (probe H9).

10. **[MED] F10 — gate-ID collision: two different gates are called G3.** The skill card
    and `references/legal-postures.md` define G3 = PD 1096 vicinity plates, but
    `scaffolding/PROC_REIMAGINE.md` Stage 2 says "no-FoP style check (**G3 style
    rungs**)" and its failure routes say "(G3 style)". The style authority is not a
    numbered gate in the card at all. An operator following PROC to the card will

11. **[LOW-MED] F11 — "tool settings" is claimed deliverable, never graded.** Stage 6

    REQUIRED_SECTIONS omits it and worksheet.schema.json leaves it optional — a
    worksheet with no Tool settings section still passes 6/6 (implicit in H1-style

12. **[LOW] F12 — doc/code contract drift on the N/A line.** CONFIG_WORKSHEET.md says the
    grader "expects exactly that line" (`N/A — text-only brief; fidelity claims dropped`)
