# Learnings — S014

1. Prompt needs arise from materially different operations: text → new 3D object, one photograph → uncertain 3D, **real multiple input views** → another reconstruction condition, and existing mesh → retexture. The four-view thumbnails returned by a single-image pipeline are outputs and add no source coverage (D05–D08). Research image-pair 3D editing (R03) is not a consumer feature promise.
2. Do not confuse a text field with every 'AI enhancement' feature. Topaz Gigapixel Redefine has conditional *Image description* and asks for descriptive statements (D12); its Face Recovery offers selection/strength/modes instead of a face prompt field (D13). The latter may change facial features according to the vendor and users (O17,O18). Adobe Photoshop selected Fill differs from Remove and can still exhibit seams/tones (D14,O10–O12).
3. Context preservation is tool-specific: SketchUp's Erase/Paint mask modes treat masked pixels differently (O04, staff), Midjourney Style Reference guides aesthetic not subjects (D16), and BFL's FLUX.2 layout instructions use image references without certifying pixel-exact ControlNet structure (D19). Old geometry-respect sliders requested in 2026 are not present-day default advice (O05).
4. Human posts are first-person experience, not validation of a candidate prompt. Qualify one record per directly read thread, retain contrary cases, and never promote inaccessible Reddit search excerpts to source evidence. Across SketchUp/Adobe/Topaz/GitHub/Hacker News, 22 readable threads identified *questions* rather than a performance rate. This session performed no image, mesh or prompt test.
5. The @Gather report remains factual without concluding recommendations; the @Review atlas deliberately labels all 34 problem-indexed formulas `[N]` and provides source-vs-output tests. Technical 3D usefulness, face fidelity, client disclosure and architecture geometry are separately inspectable rather than collapsed into one subjective “looks good” score (R01,R02,O08).
6. S012 and S013 are still unapproved working proposals; S014's new content can travel only in a cumulative proposal against the unchanged base, not through a gate pinned to a missing B4.2 SHA and unrelated nine-path charter. Suite remains red on those gate-coupled checks, without code changes to hide it.
